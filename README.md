# Hi, I'm Antonina!

I'm a software developer focused on web development.

Most of my projects are built with JavaScript and React. I also use Node.js, Express, Next.js and PostgreSQL when working on full-stack applications. I enjoy building interfaces and understanding how the whole application works — from the frontend to APIs and databases.

## Projects

### Gomellift Breakdown Monitor

A dashboard for monitoring elevator breakdown data.

The application receives data through an API, stores it in PostgreSQL and displays the latest information in a React interface.

**Stack:** React, Node.js, Express, PostgreSQL, Supabase

[Repository](https://github.com/Antonina-Dashkevich/gomellift-breakdown-monitor) · [Live demo](https://gomellift-breakdown-monitor.vercel.app/)

### User Management App

A user management application with registration, e-mail verification, authentication and account administration.

Users can register, confirm their e-mail, log in and manage other users through a protected interface.

**Stack:** React, Node.js, Express, PostgreSQL, Supabase, JWT

[Repository](https://github.com/Antonina-Dashkevich/user-management-app) · [Live demo](https://user-management-wii2.onrender.com/login)

### Song Catalog Generator

A Next.js application that generates reproducible music catalogs based on region, seed and other parameters.

It includes generated song metadata, covers, lyrics and audio previews.

**Stack:** Next.js, React, Material UI, TanStack Query, Tone.js

[Repository](https://github.com/Antonina-Dashkevich/songs-generator-app) · [Live demo](https://songs-generator-app.onrender.com/)

**Stack:** React, Node.js, Express, Prisma, PostgreSQL, Azure Blob Storage

[Repository](https://github.com/Antonina-Dashkevich/cv-management-app) · [Live demo](https://cv-app-lws0.onrender.com)
